# X-O Battle Arena 

A  Tic-Tac-Toe game implemented in C .

## 📌 Features
- Two-player mode (Player 1: `X`, Player 2: `O`)
- Validates user input and prevents invalid moves
- Detects and announces the winner or a draw
- Displays the Tic-Tac-Toe board after every move


## 🎮 How to Play
1. The game is played on a 3x3 grid.
2. Player 1 (`X`) goes first, followed by Player 2 (`O`).
3. Players take turns entering the row and column numbers (0-2) to place their mark.
4. If a player attempts to:
   - Choose an **invalid coordinate** (out of range)
   - Pick an **already occupied cell**
   The game will prompt them to enter a valid move.
5. The game ends when a player wins by forming a horizontal, vertical, or diagonal line, or when all cells are filled (draw).
